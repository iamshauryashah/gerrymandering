Build your own state

Click inside the state to add a city. Click a city to select it, then use the slider to set its population; Remove city or the Delete key removes it. Cities pull in smaller, denser precincts. Keyboard: focus the map, move the cursor with the arrow keys (hold Shift for big steps), and press Enter.
